Privacy policy

This policy describes how Pete’s Gmail Task Importer, a personal tool maintained by Pete Macke, handles Google user data.

Gmail data and purpose

The importer uses Google OAuth to access the owner’s authorized Gmail accounts. It uses Gmail labels to find messages marked .IncompTask. It may read selected messages’ subjects, bodies, dates, and identifiers to create tasks, link to the source email, and avoid duplicate imports. After a successful import, it removes the processing label from the source message.

Where data goes

The importer sends the resulting task details, which may include information from the selected email and a link to the original message, to the owner’s connected Toodledo account. The public GitHub Pages site hosts only app information. Gmail data is used to provide the import feature and is not sold, used for advertising, or used to train general-purpose AI models.

Storage, retention, and deletion

The importer is designed to run on the owner’s computer and keep OAuth credentials in secure local storage. Local import records may retain message identifiers to prevent duplicates. To stop future imports, stop the local schedule and revoke access in Google Account connections. You can remove local tokens and import records from the computer and delete imported tasks separately in Toodledo. Original messages remain subject to Gmail’s retention and deletion controls.

Google API policy

The importer’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Use the support contact shown on the Google consent screen for privacy questions.
